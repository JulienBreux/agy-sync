# Support Guidelines

Thank you for using **agy-sync**!

This document explains where to find help, how to ask questions, and where to file issues.

## Getting Help

### Documentation & Resources
- **README**: Start by reading our [README](README.md) for architecture, quickstart, schema hierarchy, and CLI commands.
- **Contributing Guidelines**: Review [CONTRIBUTING.md](CONTRIBUTING.md) to understand development and contribution conventions.
- **Built-in Help**: Run `agy-sync --help` (or `agy-sync <command> --help`) to inspect commands, arguments, and configuration flags.

### Asking Questions & Discussions
For general questions, how-tos, feature suggestions, or architectural discussions:
- Start a discussion in [GitHub Discussions](https://github.com/JulienBreux/agy-sync/discussions).

### Reporting Bugs
If you believe you have encountered a bug or unexpected behavior:
1. Search [existing GitHub issues](https://github.com/JulienBreux/agy-sync/issues) to verify if the issue has already been reported.
2. If not, open a new [Bug Report](https://github.com/JulienBreux/agy-sync/issues/new?template=bug_report.md) with reproduction steps, environment details, and logs.

### Security Inquiries
For security issues or vulnerabilities, please do not file a public issue. Refer to [SECURITY.md](SECURITY.md) for confidential reporting channels.
